# Goals Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a fifth "Goals" tab to Poplist that tracks monthly numeric objectives (e.g. "270 calls") and surfaces the calculated per-day pace as the dominant visual element on each bubble.

**Architecture:** Poplist is a single static `index.html` file (inline `<style>` + inline `<script>`, no build step, no dependencies). This plan extracts the goal math/parsing into a small standalone `goals-logic.js` (loaded via a plain `<script>` tag, no bundler) so it's testable with plain Node — everything else stays inline in `index.html`, following the existing file's pattern. Goal rendering/interaction lives in its own clearly-named functions inside the existing inline script, with the existing dispatch points (`renderList`, add button/Enter, tab click, "Start a new day") branching to them by tab `type` rather than having goals logic threaded through the task-list code.

**Tech Stack:** Vanilla HTML/CSS/JS, `localStorage` for persistence, Node.js (built-in `assert` module only, no packages) for logic tests.

## Global Constraints

- No build step, no bundler, no new npm dependencies. `goals-logic.js` is included via a plain `<script src="goals-logic.js"></script>` tag.
- 5th tab entry: `{key:"goals", label:"Goals", color:"#3fa7a0", type:"goals"}`, appended to the end of `TABS`. Existing four tabs have no `type` field (treated as tasks by its absence).
- `state.workingDays` default: `[false,false,true,true,true,true,true]` (index 0=Sun…6=Sat; Tue–Sat on, Sun/Mon off). One global setting, not per-goal.
- Pace math: `remaining = Math.max(target - current, 0)`; `perDay = Math.ceil(remaining / workingDaysLeft)`, rounded up.
- Add-goal parsing regex: `/^\s*(\d+(?:\.\d+)?)\s*(.*)$/` — group 1 is `target`, trimmed group 2 is `label`. No match → shake the input, do not add.
- `periodKey` format: `"YYYY-MM"`, computed from the app's existing 5am-aware `dayStamp()` "today" (not raw `new Date()`).
- On month rollover (goal's stored `periodKey` != current `periodKey`): reset `current=0`, `celebrated=false`, update `periodKey`. Never touch `target`/`label`.
- Bubble visual hierarchy: the per-day number is the large/hero element (Nunito 800, ~2.6rem). Total/current/remaining/workdays are small caption text (`--ink-soft`/`--ink-faint` scale, matching `.tagline`).
- No drag-reorder and no rank number for goal bubbles — order is creation order.
- Deleting a goal (`×`) is immediate, no confirmation dialog.
- "Start a new day" on the Goals tab shows an explanatory sheet, not the keep/drop/delegate review.
- Export/import payload includes `workingDays` alongside `tabs`/`delegated`.
- Spec reference: `docs/superpowers/specs/2026-07-29-goals-tab-design.md`.

```js
(function(root){
  "use strict";

  function parseGoalInput(text){
    const m = /^\s*(\d+(?:\.\d+)?)\s*(.*)$/.exec(text);
    if(!m) return null;
    return { target: Number(m[1]), label: m[2].trim() };
  }

  function periodKeyFor(date){
    const y = date.getFullYear();
    const m = String(date.getMonth() + 1).padStart(2, "0");
    return `${y}-${m}`;
  }

  function workingDaysLeft(fromDate, workingDays){
    const year = fromDate.getFullYear();
    const month = fromDate.getMonth();
    const lastDay = new Date(year, month + 1, 0).getDate();
    let count = 0;
    for(let d = fromDate.getDate(); d <= lastDay; d++){
      const dow = new Date(year, month, d).getDay();
      if(workingDays[dow]) count++;
    }
    return count;
  }

  function computePace(target, current, workingDaysLeftCount){
    const remaining = Math.max(target - current, 0);
    if(remaining === 0) return { remaining: 0, perDay: 0, noWorkingDaysLeft: false };
    if(workingDaysLeftCount <= 0) return { remaining, perDay: null, noWorkingDaysLeft: true };
    return { remaining, perDay: Math.ceil(remaining / workingDaysLeftCount), noWorkingDaysLeft: false };
  }

  function defaultWorkingDays(){
    return [false, false, true, true, true, true, true];
  }

  const api = { parseGoalInput, periodKeyFor, workingDaysLeft, computePace, defaultWorkingDays };
  if(typeof module !== "undefined" && module.exports) module.exports = api;
  else root.GoalsLogic = api;
})(typeof window !== "undefined" ? window : globalThis);
```

  function flashInputError(){
    input.classList.add("shake");
    setTimeout(()=>input.classList.remove("shake"),450);
  }

  function addGoal(){
    const v=input.value.trim();
    const parsed=GoalsLogic.parseGoalInput(v);
    if(!parsed){ flashInputError(); return; }
    state.tabs.goals.push({
      id:uid(), target:parsed.target, label:parsed.label, current:0,
      periodKey:GoalsLogic.periodKeyFor(dayStamp(new Date())),
      celebrated:false, createdAt:Date.now()
    });
    input.value="";
    renderTabs(); renderList(); save();
  }

  function deleteGoal(id){
    const arr=state.tabs.goals;
    const idx=arr.findIndex(x=>x.id===id);
    if(idx>-1) arr.splice(idx,1);
    renderTabs(); renderList(); save();
  }
